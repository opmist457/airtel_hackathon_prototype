Technology Stack
Modern, lightweight, and production-ready technologies
⚛️

Frontend Framework

  • React 19 with functional components & hooks
  • Vite 6 for lightning-fast dev and builds
  • React Router v7 for client-side navigation
  • 100% vanilla CSS — zero framework dependency
🎨

Design System

  • Custom glassmorphism design language
  • Dark-mode first with Airtel Red accents
  • Responsive grid with fluid typography
  • CSS animations (no JS animation libraries)
🗄️

Data & APIs

  • JSON-based mock APIs from converted CSVs
  • 3,534 GSTIN + 2,723 Udyam real-structure records
  • 5,000 lead analytics records with funnel data
  • 25-product catalogue with segment mapping
✅

Validation Logic

  • Custom GSTIN checksum algorithm (Luhn mod-36)
  • Udyam format validator with state code checks
  • Real-time field validation with error messages
  • Multi-step form validation with progress tracking
🛡️

Privacy & Compliance

  • DPDP Act 2023 compliant consent flows
  • Granular consent with purpose limitation
  • PII masking (GSTIN: 22AAAAA****A1Z5)
  • Client-side data protection and secure sessions
🚀

Performance

  • Single-page app with lazy-loaded routes
  • Optimistic UI updates for instant feedback
  • Debounced search and throttled API calls
  • CSS-only animations for 60fps smoothness
